# RSS 聚合器卡片墙重设计 Spec

> 日期：2026-09-02
> 状态：待实施
> 原型：`artifacts/design/rss-reader-redesign.html`

## 1. 目标

将现有三栏布局（信源侧栏 | 文章列表 | 阅读区）改为**卡片墙 + 抽屉阅读器**，显著降低视觉重量，同时保留信源筛选能力。

## 2. 布局变更

### 2.1 旧布局（三栏）
- 左侧：信源分类树 + 搜索框（常驻，~20% 宽度）
- 中间：文章标题列表
- 右侧：阅读区（固定宽度）

### 2.2 新布局（卡片墙 + 抽屉）
- **顶部工具栏**：标题 + "信源"按钮 + 分类 chip + 筛选 pill + 元信息
- **主区域**：CSS Columns 卡片墙（自适应 4 列 → 1 列）
- **左侧抽屉**：信源面板（按需滑出，搜索 + 分类折叠 + 信源列表）
- **右侧抽屉**：阅读器（点击卡片滑出，快览/全文切换）

## 3. 信源数据

**唯一数据源**：`build_rss_aggregator.py` 中的 `RSS_SOURCES` 列表（87 个源）。

前端展示的信源必须与该列表完全一致，不使用硬编码的 demo 数据。

### 3.1 分类顺序
```
ai → tech → cn_tech → dev → news → podcast
```

### 3.2 默认视图
- 页面加载时默认显示**全部分类**的卡片墙
- 不再默认选中某个信源或时间线

## 4. 卡片设计

每张卡片包含：
- 顶部：分类标签（彩色圆点 + 大写英文）+ 相对时间 + 外链按钮
- 标题：Noto Serif SC 字体，最多 3 行，hover 变品牌色
- 摘要：最多 4 行，灰色
- 底部：信源圆点 + 信源名 + 阅读时间 + "无全文"标签（如有）
- 已读状态：标题变灰 + "已读"标签

## 5. 信源面板（左侧抽屉）

- 触发：工具栏"信源"按钮
- 宽度：340px（最大 90vw）
- 内容：
  - 搜索框（实时过滤信源名称）
  - "全部信源"入口（显示总文章数）
  - 按分类折叠分组（点击分类标题可折叠/展开）
  - 每个信源：彩色圆点 + 名称 + 文章数
- 选中信源后：
  - 卡片墙过滤到该信源的文章
  - 工具栏显示深色 fpill 标签（信源名 + ✕ 清除）
  - 分类 chip 取消高亮

## 6. 阅读器（右侧抽屉）

- 触发：点击卡片
- 宽度：760px（最大 100%）
- 顶部：返回按钮 + 信源信息 + 快览/全文切换 + 原站链接 + 阅读进度条
- 内容：
  - 标题（Noto Serif SC, 23px, 900 weight）
  - 元信息行：分类 + 信源 + 时间 + 阅读时间
  - 快览模式：显示 RSS 摘要
  - 全文模式：显示站内全文分片（如有）
  - 无全文降级：虚线卡片 + "前往原站"按钮
- 关闭：点击遮罩 / ESC / 返回按钮

## 7. 筛选逻辑

```javascript
var filter = { type: 'all', cat: null, src: null };
// type: 'all' | 'cat' | 'src'
```

- `type: 'all'`：显示全部文章
- `type: 'cat'`：显示指定分类的文章（点击 chip）
- `type: 'src'`：显示指定信源的文章（点击信源面板中的信源）
- 分类和信源互斥

## 8. 键盘导航

- `J` / `→`：下一篇
- `K` / `←`：上一篇
- `ESC`：关闭抽屉/面板

## 9. 响应式

- `≤900px`：隐藏 logo 副标题和 badge，工具栏 padding 缩小
- `≤700px`：chip 横排滚动，阅读器顶部按钮文字隐藏

## 10. 实施步骤

1. 重写 `build_rss_aggregator.py` 的 HTML 模板部分
2. 保留 Python 端的 RSS 抓取、翻译、缓存逻辑不变
3. 前端 JS 改用卡片墙渲染 + 抽屉交互
4. 信源数据从 `RSS_SOURCES` + `rss_cache.json` 动态生成
5. 本地构建验证 → 提交 → CI 部署

## 11. 保留的现有功能

- 主题切换（明/暗）
- 客户端翻译 API（Google Translate gtx）
- 实时刷新（api/rss.js）
- 已读标记（localStorage）
- 相对时间显示

## 12. 移除的功能

- 三栏布局
- 常驻信源侧栏
- 时间线视图（合并到卡片墙，按时间排序）
- iframe 内嵌原文（改为"原站 ↗"外链）
